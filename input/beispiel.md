# Produkthandbuch

Einleitender Text zum gesamten Handbuch. Er beschreibt kurz, worum es geht.

## Installation

Die Installation erfolgt in wenigen Schritten. Zuerst wird das Paket heruntergeladen. Danach entpackt man das Archiv in ein beliebiges Verzeichnis. Anschließend startet man das Setup-Skript. Das Setup prüft alle Systemvoraussetzungen automatisch. Bei Problemen hilft das Log im Ordner logs weiter. Nach erfolgreichem Setup ist ein Neustart empfehlenswert. Die Konfiguration kann anschließend angepasst werden. Alle Einstellungen liegen in einer zentralen Datei. Änderungen werden beim nächsten Start übernommen. Für Updates gibt es einen eigenen Befehl. Dieser lädt nur die geänderten Komponenten. So bleibt die Installation schlank und aktuell. Wer möchte, kann auch den Entwicklungszweig nutzen. Dieser enthält die neuesten Funktionen, ist aber weniger stabil. Für den Produktivbetrieb wird der stabile Zweig empfohlen.

### Systemvoraussetzungen

| Komponente | Minimum | Empfohlen |
|------------|---------|-----------|
| RAM        | 4 GB    | 16 GB     |
| CPU        | 2 Kerne | 8 Kerne   |
| Disk       | 10 GB   | 50 GB     |

### Bekannte Probleme

- Setup bricht bei fehlenden Schreibrechten ab
- Proxy-Umgebungen brauchen extra Konfiguration
- Ältere Betriebssysteme werden nicht unterstützt
