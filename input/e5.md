# E5 (multilingual-e5) Text Embeddings

## Übersicht
E5 ("EmbEddings from bidirEctional Encoder rEpresentations") ist eine Embedding-Familie von Microsoft (Autoren u.a. Liang Wang, Nan Yang, Furu Wei). Die ursprüngliche englische E5-Serie (Dez. 2022, arXiv:2212.03533) etablierte das Rezept aus großskaligem **weakly-supervised contrastive pre-training** gefolgt von supervised Fine-Tuning. Der **multilingual-e5**-Ableger (Technical Report Feb. 2024, arXiv:2402.05672) überträgt dieses Rezept auf 100 Sprachen und ist eines der meistgenutzten offenen mehrsprachigen Embedding-Modelle für RAG. Verfügbar in drei Größen: small, base, large (plus eine instruction-tuned Variante `multilingual-e5-large-instruct`).

## Architektur
E5-Modelle sind **Encoder-only Transformer** (bidirektional, BERT/RoBERTa-Stil). Die englische Serie basiert auf BERT-Varianten; **multilingual-e5-large** initialisiert von **XLM-RoBERTa-large** (24 Layer, Hidden 1024). Das Satz-Embedding entsteht durch **Mean-Pooling** über die Token-Hidden-States (nicht [CLS]), danach L2-Normalisierung; Similarity via Kosinus.

Eine zentrale Eigenheit ist der **Prefix-Mechanismus**: Eingaben müssen mit `"query: "` oder `"passage: "` präfixiert werden. Für asymmetrische Retrieval-Aufgaben wird die Query mit `query:` und das Dokument mit `passage:` versehen; für symmetrische Aufgaben (Similarity, Clustering, Klassifikation) wird durchgehend `query:` verwendet. Ohne Prefix degradiert die Performance deutlich.

**Trainingsrezept (zweistufig):**
- **Stufe 1 — Weakly-Supervised Contrastive Pre-Training** auf ~1 Mrd. mehrsprachigen Textpaaren, u.a. 1B gefilterte mC4, 400M CC News, 2.4B NLLB-Übersetzungspaare, 150M Wikipedia, 800M gefilterte Reddit-Paare, 100M S2ORC, 50M StackExchange, 80M xP3, 10M unsupervised SBERT-Daten. InfoNCE-Loss mit In-Batch-Negatives.
- **Stufe 2 — Supervised Fine-Tuning** auf gelabelten Datensätzen: MS MARCO, Natural Questions, TriviaQA, NLI, ELI5, DuReader Retrieval, KILT (FEVER, HotpotQA), SQuAD, Quora, Mr. TyDi (11 Sprachen), MIRACL (16 Sprachen), mit Hard Negatives.

## Benchmarks
- **Mr. TyDi** (mehrsprachiges Retrieval): multilingual-e5-large erreicht Durchschnitt **MRR@10 ≈ 70.5**, deutlich über BM25 (33.3), mDPR (16.7) und kleineren E5-Varianten (Model Card).
- **MTEB**: hohe Werte über Tasks hinweg; z.B. AmazonCounterfactualClassification EN Accuracy 79.06 %, DE 71.22 % (Model Card). Vollständige MTEB-Aufschlüsselung über "Expand evaluations" auf der Card.
- Die instruction-getunte Variante erreicht laut Technical Report Parität mit englisch-only State-of-the-Art-Modellen ähnlicher Größe.

## Besonderheiten / Trivia
- E5 popularisierte das inzwischen weit verbreitete "query:/passage:"-Prefix-Schema für asymmetrisches Retrieval.
- Das E5-Rezept (contrastive pretraining auf Web-Paaren → supervised FT) wurde zur Blaupause für viele nachfolgende Modelle.
- Technical Report (arXiv:2402.05672) ist unter CC BY 4.0 lizenziert; die Modell-Gewichte unter MIT.
- E5-mistral-7b-instruct (separates Modell) nutzt ein LLM (Mistral-7B) als Backbone und synthetische Daten — ein anderer Zweig derselben Autoren.
